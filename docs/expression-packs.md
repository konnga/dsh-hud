# 自定义思考表情包

表情包是图片与动作的映射，不是插件或脚本。第一版支持**静态 PNG / WebP 的工具联动表情切换**，不支持 GIF、APNG、动态 WebP 或帧序列。

## 使用入口

首次更新此功能后，重启 DSH 以加载新增宿主接口。之后导入、保存、替换图片和切换表情包均无需重新构建或重启。

1. 打开 HUD 齿轮 → **表情包**。
2. **用图片创建**：选择一张或多张 PNG / WebP，填写名称并设置动作映射。符合动作 ID 的文件名可自动匹配，其余通过下拉选择；只准备一张图也能使用。
3. **导入 ZIP**：读取下述格式，先进入编辑预览，不会自动保存或启用。
4. 检查动作缩略图与放大预览，确认后保存，再点击使用。表情包页顶部的「当前使用的表情包」与「常规」使用同一套卡片，集中切换内置角色与已导入的包。
5. 编辑时可替换单张图、修改映射或清除非默认动作。保存使用修订号校验；其他窗口已更新同一包时会提示重新加载，避免覆盖对方修改。
6. 导出保存后的包用于备份和分享。重复导入不会按名字覆盖已有包：新建和编辑是不同操作。删除需要确认；删除正在使用的包后恢复原版鲸鱼娘。

**只要求 `thinking` 动作。** 未配置的动作使用当前包的 `thinking`，文案和工具状态仍正常更新，不会穿插另一角色的图片。内置 Q 版鲸鱼娘、赛博鲸鱼娘与长裙鲸鱼娘保留独立资源，设置提供官方及三套角色选择。旧纸飞机偏好会回退到默认 Q 版鲸鱼娘。

## 可导入示例

[赛博鲸鱼娘 · 30 动作标准包](expression-packs/cyber-whale-girl.zip) 可直接从管理页导入，导入后作为独立自定义包保存，不覆盖内置套图。它只包含版本化清单和实际使用的静态图片。

## ZIP 格式（schemaVersion 1）

压缩包根目录必须是 `manifest.json`，图片放在 `images/` 下，不要再套一层文件夹。

```text
my-pack.zip
├── manifest.json
└── images/
    ├── thinking.png
    ├── reading.webp
    └── typing.png
```

```json
{
  "schemaVersion": 1,
  "name": "我的鲸鱼娘",
  "author": "作者名（可省略）",
  "version": "1.0.0",
  "fallback": "thinking",
  "actions": {
    "thinking": "images/thinking.png",
    "reading": "images/reading.webp",
    "typing": "images/typing.png"
  }
}
```

文件名、动作名区分大小写；图片路径只引用本包，不允许外部 URL、绝对路径或脚本。推荐简单英文字母、数字、连字符与下划线组成的文件名。`version` 是作者填写的版本说明，宿主另外生成内部修订号用于并发检查和图片更新，二者用途不同。

### 支持的 30 个动作 ID

```text
thinking context connect ponder writing checking
 typing watching reading inspecting searching working
question butterfly gears puzzle thread sketching
flashlight binoculars map measuring toolbox notes
rice_eating rice_cheeks rice_terminal rice_ponder rice_reading rice_notes
```

可以把多个动作映射到同一张图。图片保留原始比例，显示时使用 `object-fit: contain`；不自动裁剪头发、尾巴或道具。推荐透明背景、清晰的主体轮廓，并在 56px 实际显示尺寸下检查可辨识度。

## 限额与保存范围

- 最多 20 个自定义包，每包最多 30 张图片。
- 单张图片不超过 2 MiB，宽高各不超过 1024px。
- 每包原始图片合计不超过 12 MiB；导入 ZIP 不超过 16 MiB。
- 支持 PNG、静态无损或有损 WebP；校验内容而不只看扩展名。导入检查文件完整性、尺寸、动作引用和解压后总量，浏览器在保存前逐张解码检查。
- 自定义包和选中状态由宿主 `storageDomain` 管理，使用独立的 `dsh_hud_expression_packs` 数据域，不写入插件安装目录、项目源码或模型凭据。域名遵循 DSH 的字母、数字、下划线规则；逐记录存储键去除对外 ID 的 `custom:` 前缀，包内容与选择仍使用完整 ID。
- 浏览器只保留当前需要的资源缓存及原有小型显示偏好，不把图片塞进 localStorage。保存成功以宿主写入成功为准。
- 数据保存在当前 DSH 宿主，不会自动云同步到另一台机器；迁移请导出 ZIP。

## 故障提示

- **需要重启**：网页已加载新客户端，但宿主尚未注册新增接口。
- **存储不可用**：当前宿主没有相应持久化能力或存储无法打开；不会用临时内存冒充保存成功。
- **保存冲突**：同一包的修订号已改变；重新读取后再编辑。
- **同步失败**：保留当前窗口的已有显示，提示重试；不会悄悄覆盖用户的本地选择。
- 图片正在加载或解码时不会重置状态或推进表情；同名替换由内部修订号区分，旧解码回调不能把新图覆盖回去。包暂时无法读取时保留官方图标兜底，不误删自定义包偏好。

减少动态效果时，同组表情固定为池中第一张，模型阶段与工具变化仍更新文案。这里的“动画”指多张静态表情按事件切换，不代表图内有逐帧动作。

此前交付的设计素材归档含 PNG 导出、预览和制作清单，**不是本规范的可导入包**。分享时请使用管理页面的「导出 ZIP」，或者严格按照上述结构制作。
