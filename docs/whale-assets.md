# 鲸鱼娘资源维护

## 目录约定

| 路径 | 用途 | Git / 发布 |
| --- | --- | --- |
| `src/client/assets/whale-girl/*.webp` | 原版鲸鱼娘的 30 张 224px 无损 WebP 动作图（含透明通道） | 进 Git；构建后嵌入 JS |
| `src/client/assets/cyber-whale-girl/*.webp` | 赛博鲸鱼娘的 30 张 224px 无损透明 WebP；蓝发、耳机、工装与完整鲸尾 | 进 Git；构建后嵌入 JS |
| `src/client/assets/longdress-whale-girl/*.webp` | 长裙鲸鱼娘的 9 张 224px 无损透明 WebP；覆盖思考、读写、搜索与趣味动作 | 进 Git；构建后嵌入 JS |
| `src/client/running-cues.ts` | 中英文文案及动作映射 | 进 Git |
| `src/client/whale-assets.ts`、`src/client/cyber-whale-assets.ts` | 两套 WebP 分别转成 data URL 的生成模块 | Git 忽略；自动生成 |
| `lib/client.js` | DSH 实际加载的构建产物，已包含图片数据 | 沿用项目构建产物约定 |
| `docs/images/whale-girl-preview.webp`、`docs/images/cyber-whale-girl-preview.webp` | README 的两套独立展示图 | 进 Git / 发布包 |
| `docs/images/whale-girl/` | 本地讨论、参考图、原始 API 输出、多尺寸导出、交互预览与检查工具 | 整目录 Git 忽略；不进发布包 |

运行与构建都不读取 `docs/images/whale-girl/`。删除或缺少本地讨论目录，不影响干净检出的构建、类型检查和测试。无需 Python、生图服务或 API 密钥。

设置提供官方、Q版鲸鱼娘、赛博鲸鱼娘、长裙鲸鱼娘四项。赛博鲸鱼娘的皮肤 ID 为 `cyber-whale`，长裙鲸鱼娘的皮肤 ID 为 `longdress-whale`；两者与 Q 版 `whale` 使用独立图片。长裙版未覆盖的动作回退到 `thinking`。旧纸飞机或轮播偏好会回退到默认 Q 版鲸鱼娘。

## 可视化设置

入口为输入框上方 HUD 行末尾的齿轮胶囊，设置浮层挂在 `shell.overlay`，不另占一条 dock 行。面板以「常规」「余额管理」两个 tab 分组，支持方向键与 Home / End 切换；每次打开默认回到常规页，余额页仅在选中时挂载并读取站点。DSH 的通用设置提供相同的四种皮肤快捷选择，复用同一个 `SkinRow` 和状态；两处即时同步。

- 胶囊显示：Git、工具与技能、余额、会话计时可分别开关，默认全部显示；齿轮设置入口始终保留。
- 余额管理：列出已配置的中转站，按需查询余额并展示 API 密钥和网页令牌配置状态，不改变当前会话模型。API 密钥与网页令牌均默认遮罩，分别提供查看/隐藏和复制图标，用户点击查看或复制后才读取对应字段；隐藏、切换 tab、关闭、刷新列表或窗口失焦会清理显示值。地址、API Key 与网页令牌均有复制图标，遮罩状态可按需读取并直接复制；清理显示值时也取消尚未完成的复制读取。复制仅由用户点击触发，有成功或失败反馈，不自动显示明文。密钥不写入 localStorage，也不进入诊断日志。余额页省略重复标题与说明，刷新、查询、查看与复制均使用带可访问名称和悬停提示的图标按钮。
- 尺寸：32 / 40 / 48 / 56 / 64 / 72 / 80 / 96 / 104px；默认 56px，源图片为 224px 无损 WebP。之所以用 2 倍尺寸：104px 档在 2 倍屏上需要 208 个物理像素，源图只有 112px 时会被放大而发虚。显示时仍按 `object-fit: contain` 等比缩放，不会裁切。
- 显示由真实执行状态驱动：主文案跟随模型阶段与工具调用，表情只在事件身份变化时更换；旁边的趣味短语从全库共用的池子里每 6 秒随机换一句（不与上一句重复，悬停或聚焦时暂停），不复述事实。不提供固定间隔配置，旧 `rotateMs` 值不再参与轮播或新偏好的持久化。
- 表情图片走**单一全库池**：30 个动作各出现一次，不按当前工具筛选。顺序按「相邻两张语义拉得开」排列，避免连续两次新调用看到相近的姿势。同一次调用内不换图，新调用才推进到下一张；池子走完一圈再从头。减少动态效果时固定在池首。全部 200 条口语短句作为趣味短语保留并轮换，不提供独立开关。
- 用时：默认显示；关闭只隐藏 HUD 的用时，不改变宿主计时或官方皮肤。
- 开关状态：蓝色轨道、圆点在右并显示“开”表示开启；灰色轨道、圆点在左并显示“关”表示关闭。启用色使用 DSH 的蓝色令牌，不使用深色主题中近白色的 `brand-primary`。
- 恢复默认：恢复上述显示偏好，并选回鲸鱼娘。

设置状态由 `src/client/hud-settings.ts` 提供，保存到 `dsh-hud:display-settings`。皮肤仍使用原键 `dsh-hud:running-skin`，不覆盖已有选择。旧 `playful`、`rice` 偏好均不再生效，即使曾保存为关闭也会使用全部动作；保存时会移除旧字段。开关设置面板不会推进表情或取消图片解码。存储损坏会回到显示默认值；保存失败仍保持本次选择并提示未能保存，跨窗口设置变更与返回窗口时会同步。

三套鲸鱼娘共用图尺寸设置、完整状态文案、事件驱动的表情选择与用时开关。模型提示词、参数、输出和工具执行不受这些本地显示设置影响。设置面板实现了对话框语义、首次焦点、Tab 边界循环和关闭后返回入口焦点。

## 更新运行图片

1. 把确认后的动作图放到对应的 `src/client/assets/whale-girl/`、`src/client/assets/cyber-whale-girl/` 或 `src/client/assets/longdress-whale-girl/`：224 × 224px、无损 WebP（RGBA，保留透明度）；两套文件名都完整对应 30 个动作 ID，如 `rice_eating.webp`。两套图片分开维护，不互相覆盖。
2. 新增动作时同步更新 `src/client/running-cues.ts` 的 `WhaleAction` 与文案映射。
3. 执行：

```sh
pnpm build
pnpm test
pnpm format:check
```

`build`、`test`、`typecheck` 都会先运行三个角色资源生成脚本，分别从 `src` 自动生成内嵌模块。不要手改或提交生成的 `whale-assets.ts`、`cyber-whale-assets.ts`；类型检查会核对动作映射，测试会核对原 WebP 与构建产物中的图片字节。

图片必须使用无损编码，不接受有损或动画 WebP。转换时启用 `lossless=True` 和 `exact=True`，逐张比较解码后的 RGBA，包含透明像素下的颜色。构建只校验 WebP 容器、无损编码、尺寸和透明标记，不执行格式转换，因此不依赖图片处理库。

客户端仍然使用 data URL 而不是运行时相对路径，适配 DSH 的经典脚本模块加载方式。图片在界面里默认显示为 56px；用时在文案上方。切换动作时先在界面外加载并解码，期间保留旧图与旧文案、继续更新用时；新图准备好后同拍替换，不清空文字、不重放淡入，也不闪回官方图标。首张加载失败保留官方图标，后续候选失败保留最后一张成功图片并继续更新文案。状态行保留至少 56px 高度。资源更新后重启本地 DSH 读取新构建。

## 文档与本地材料

README 需要展示图片时，复制或缩小一份到 `docs/images/` 顶层，不链接 Git 忽略的讨论目录。发布配置只纳入该目录顶层的 WebP 文档图，不附带原图、重复尺寸、离线预览或其他本地导出。

参考原图和高分辨率候选仍在本地保存，便于继续制作；它们不是生产依赖。旧导出与审图脚本已收进本地 `docs/images/whale-girl/v4/tools/`，只产生本地文件，不自动覆盖 `src` 中的正式资源。

赛博鲸鱼娘基于用户提供的蓝发工装参考图，使用皮皮智绘 `image-1` 生成。第一渠道因分组没有生图权限而未产出；最终采用 5 张六格动作图及 1 张修正图，修正了地图、卡片姿势和端饭理卡片道具。所有 30 张图均检查完整鲸尾、透明边缘、112px 无损 RGBA 往返一致性与 56px 深浅背景效果。这里的“思考动画”是沿用现有动作切换机制，并非每张图内部逐帧摆尾。

本地 `docs/images/whale-girl/cyber-whale/` 保留参考图、原始输出、透明 PNG 导出、制作脚本、轮播展示、素材 ZIP 和校验清单；均被现有讨论目录忽略规则排除。ZIP 是素材归档，不是程序的导入格式。API 密钥不写入这些文件或构建产物。
