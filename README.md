# dsh-hud

> DeepSeek Harness 的当前工作区面板：分支、ahead/behind、脏状态、改动清单与差异（全部只读），并告诉你**这个会话改过哪些文件**、**审到哪了**。
> A read-only workspace Git panel for DeepSeek Harness — plus per-session change attribution and review progress.

## 安装

在桌面端「设置 → 插件 → 添加插件」里填包名 `@konnga/dsh-hud`。

本地开发时把 profile 的依赖指向仓库（改动即时可见；客户端代码仍需重启应用才重读）：

```json
"@konnga/dsh-hud": "link:/path/to/dsh-hud"
```

## 界面

### 胶囊（输入框上方那一行）

`⎇ feat/x* ↑1 ↓2 M4 A1 ?1 │ ●3`

- `⎇ 分支`：detached 时是 `detached <短oid>`；过长中段省略。
- `*` 工作区不干净；`↑n` / `↓n` 与上游的领先 / 落后（为 0 不显示）。
- 简写符只列非零项：`M` 已修改 · `A` 已暂存新增 · `D` 已删除 · `R` 重命名 · `C` 复制 · `T` 类型改变 · `?` 未跟踪 · `!` 冲突。
- `│ ●n` 表示本会话改过 n 个文件（没有就不显示）。
- 点胶囊开面板；悬停给出工作区路径、上游与各类计数。

### 工具胶囊（与 Git 胶囊**同一行**，紧接在它右边）

`🛠 bash 1.2s` —— 正在跑什么、已经跑了多久（**秒数本地 500ms 滴答**，不跟轮询跳）。

- 空闲时：`✓ 54 次调用 · 最近 bash（共 3 种工具）` —— **总次数在前、最近一次在后**，并且报出共几种工具。（写成 `bash ×54` 会被读成"bash 跑了 54 次"，实测确实会让人以为只记了 bash。）
- 最近一次失败就打 `✗`。
- 悬停：现在在跑什么（含命令/路径摘要）、总次数、各工具次数、最近 3 条的成败与耗时。
- **和 Git 胶囊并排**在同一行（产品的 dock 是竖列：一条注册 = 一整行，所以它必须是那一行里的第二个节点，不能自己注册一条，否则会另起一行）。
- **完全没跑过工具时这一枚不画**，但那一行仍在（Git 胶囊不动，界面不会跳）。

### 面板

标题栏可拖动（双击复位），`⟳` 刷新 · `⌖` 复位位置 · `✕` 收起。自上而下：

1. **仓库路径 · 上游 · 短 oid**。
2. **改动概览**：按类型分组的彩色计数，只显示非零项；干净时写「工作区干净」。
3. **本会话改了哪些**：`本会话改过 3 个文件 · 另有 2 个可能相关 · 1 个已不在 git 现状里`，右边一排开关：
   - `只看本会话改的`：清单只留本会话动过的文件（含「可能相关」）。
   - `侧栏 常亮 / 悬停 / 关`：侧栏会话行上那枚状态标记的档位，**默认常亮**。
   - `只看最近一轮`：只留最近一轮改过的文件（拿得到回合信息时才出现）。
   - `已审 3/8` 与 `清空已审`：有已审标记时才出现。
4. **改动清单**：每行 `标记 状态字母 路径`，重命名读作 `旧 → 新`。
   - 行首三态：`●` 确定改过（经写文件 / 编辑工具）· `◐` 可能相关（从 shell 命令里看出来的，悬停给出那条命令）· `○` 与本会话无关。
   - 行尾 `○` / `✓`：审阅标记 —— 点一下或按 `v` 切换；`✓` 变黄表示**改动已变，需要重看**。
   - 点任意一行打开该文件的差异。
5. **最近提交**：`短sha 标题 [HEAD] 相对时间`；点一行打开这次提交的明细，再点一次收起。
6. **标签**：`tag 名 短sha [HEAD] 相对时间`，最新的在前；**仓库没有标签时也显示一行「这个仓库还没有标签」**（整段不画的话，会让人以为这个功能没做 —— 实测踩过）。**点一行就看它指向的那次提交**（复用右栏的提交明细，不新增界面）；指向当前 HEAD 的标 `HEAD`。悬停能看出是附注标签还是轻量标签、以及主题。超过 100 个时只显示最近 100 个并注明。

### 差异与提交明细

- 打开差异后是两栏：左栏就是面板本身（一字不变），右边是差异。工具栏给出路径、`+新增 -删除`、`未暂存` / `已暂存` 页签、`自动换行`、`复制差异`、`✕`。
- 点 hunk 头折叠那一段；拖右边缘调宽度（默认 470px，记住）。
- 打开提交明细时是**三栏**（面板 │ 这次提交 │ 差异），并自动打开这次提交的第一个文件。`Esc` 或 `✕` 收起。

### 侧栏会话行上的状态（按需展开，不含行内标记）

侧栏那一行**本身不再有任何标记** —— 早先的 `●n` / `◐n` / `!n` / `✓` / `—` / `?` / `+` 全部删掉了：一格里塞两件事、还要背八个符号，实测没人看得懂。信息改在**按需展开**的地方，而且都是文字：

- **`⋯` 菜单**（行尾那颗按钮）：两行 —— `主分支* ↑0 ↓0 · 已修改 7 未跟踪 2` 与 `本会话改过 3 个文件 · 命令旁听到 4 个可能改动的路径（1 个现在有差异）`；干净时明说「工作区干净」「本会话没有改动记录」。
- **悬停卡片**（同一条会话行悬停停住后弹出）：同样两行。

工作区脏不脏，看**胶囊**（`M27 ?89`）或面板顶部的改动概览即可 —— 那两处本来就是文字与数字，不需要图例。

## 键盘

**先在面板里点一下**（或 Tab 进去）才接管按键；点到面板外就交还。带 Cmd/Ctrl/Alt 的组合键与输入框里的按键一律不碰。

| 键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在清单里上下移动选中行（只移动，不打开） |
| `Enter` | 打开选中的那条 |
| `[` / `]` | 上一个 / 下一个文件，并直接打开 |
| `n` / `p` | 下一个 / 上一个 hunk（跳到折叠着的会展开它） |
| `Space` | 折叠 / 展开当前 hunk |
| `v` | 把当前行标成「这一版我审过了」（再按取消） |
| `r` | 重新读取 |
| `Esc` | 退一层：先收右栏（差异 / 提交明细），再按才收面板 |

打开提交明细时，`↑ ↓ Enter [ ]` 作用于明细那一栏的清单。

## 存在浏览器里的东西

| 键 | 内容 |
| --- | --- |
| `dsh-hud.ui.v1` | 面板展开状态、拖动位置、宽度、开关（含侧栏档位） |
| `dsh-hud.reviewed.v1` | 「已审」标记：按「工作区 + 文件」记下审过的那一版签名，最多 200 条 |
| `dsh-hud.debug` | 自诊断最近 24 行（排查「界面没反应」用，可随手删） |

## 已知边界

- **只读**：不执行 `add` / `commit` / `checkout` / `fetch` 等任何写操作，不碰 index、工作区与 git 配置，不读文件内容、不显示凭证。
- **"可能相关"有两个数，界面都写清**：`命令旁听到 n 个路径` 是**历史**（自记录起命令里提到过的，含已经还原/被 `.gitignore` 忽略的），`其中 k 个现在有差异` 才是与当前 git 清单求交的结果 —— 面板那一行的「另有 k 个可能相关」用的是后者（现在）。
- **归因分两档**：经写文件 / 编辑工具的算「确定改过」；shell 命令里认得出的算「可能相关」（`>` `>>` `tee`、`sed -i` / `perl -i`、`mv` / `cp` / `rm` / `touch` / `dd of=`、`git checkout|restore <path>`）。**会漏也会多报**，所以那一档永远是 `◐`，不冒充 `●`；其余命令只记进命令历史，不猜路径。
- **不持久化**：记录活在宿主进程里，所以每个会话都带一个「自 … 起记录」的时刻。上限：单会话 500 个文件、32 个会话、命令历史 20 条。
- **审阅签名**用 `size + mtimeMs`：`touch` 一下（内容没变）也会让「已审」失效 —— 宁可让人多看一眼。
- **计数口径**：改动计数按**文件**算 —— 未跟踪用 `git status -uall`（目录不折叠），与编辑器一致；同一文件"既暂存又改动"算 **1** 条（`git status` 的分节视图会把它列两次）。改动清单上限 200 条，超出只计数并标 `truncated`。
- **工具活动的边界**：与归因同源（旁听 `tools/pre-execute` / `post-execute`），所以同样**不持久化**、只从宿主进程启动起算；参数摘要只取路径/命令类字段，命令原文会像"可能相关"那里一样出现在悬停里。
- **标签的边界**：只读；**附注标签显示的是它指向的提交 sha**（不是 tag 对象的 sha —— 这样能和"最近提交"对上）；`refs/tags` 上限 100 个，超出只报 `truncated`。
- **性能**：面板轮询 8s；工具活动 3s（宿主那一端是**内存读**，不碰 git / 不跑子进程，密一点才看得到"正在跑"；内容没变就不触发重渲染）；侧栏摘要 30s（只在悬停卡片 / `⋯` 菜单里按需展示，没必要那么勤地问 git）；git 读取按目录缓存，多个会话共用同一个目录只跑一次。

## 开发

```bash
npm test                          # node --test test/*.test.mjs
node --test test/diff.test.mjs    # 单个文件
```

- `lib/index.js`：宿主半（跑 git、提供 `/dsh-hud-rpc`）。
- `lib/client.js`：浏览器半（**无构建步骤**，手写 JS，只依赖种子模块 `react`）。
- `test/`：单测 + 一套假 window/document/React harness。
- `docs/dock-slot-host.md`：把输入框上方那一行做成「可注册行内宿主」的提案（给上游看的）。
- 发布：`npm publish` 会先跑全部测试（`prepublishOnly`）。
